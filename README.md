# house-price-prediction
Predicting house prices using Machine Learning. Implemented Linear Regression, Random Forest, and Gradient Boosting models achieving 90% R² accuracy. Includes data cleaning, feature engineering, and visualization. Dataset: Kaggle House Prices Competition.
# House Price Prediction 🏠

## Overview
Predicting house prices using Machine Learning models achieving 90% accuracy (R² = 0.90)

## Models Used
| Model | R² Score |
|---|---|
| Linear Regression | 0.64 |
| Random Forest | 0.88 |
| Gradient Boosting | 0.90 🏆 |

## Steps Followed
- Data Cleaning & Handling Missing Values
- Feature Engineering
- Model Training & Evaluation
- Visualization of Results

## Libraries
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

## Dataset
Kaggle House Prices Competition
